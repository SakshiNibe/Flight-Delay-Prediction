# Flight Delay Prediction ✈️

A simple Machine Learning project that predicts whether a flight will be **Delayed** or **On Time**.

## Technologies

* Python
* Flask
* HTML
* CSS
* JavaScript
* Pandas
* Scikit-learn
* Random Forest

## Features

* Select Airline
* Select Source and Destination
* Enter Travel Date
* Enter Departure Time
* Predict Flight Delay
* Show Delay Probability

## How to Run

Install libraries:

```bash
pip install flask pandas numpy scikit-learn joblib
```

Train the model:

```bash
python train_model.py
```

Run the application:

```bash
python app.py
```

Open:

```text
http://127.0.0.1:5000
```
